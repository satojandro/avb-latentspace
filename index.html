How to read the machine

How a language model thinks, built from my life.

This is a real transformer forward pass, small enough to see. A model doesn't store sentences. It turns each word into a vector, a list of numbers, and every layer adds to that vector until it points at the next word. The space those vectors live in is latent space. Here, the neurons are things that shaped me, and the next word is a project.

This model: 8 dimensions, 4 blocks, 26 neurons, 5 output tokens, weights set by hand. Llama 3 8B: 4,096 dimensions, 32 blocks, 14,336 neurons per block, 128,256 tokens, weights learned.

  1. 1 · EmbedWords become vectors.

    The prompt is three tokens: "I", a context word, "build". Turn the knob on the card reader to change the context word.

  2. 2 · Attend"build" looks back at the prompt.

    An attention head scores each earlier token and copies in what it finds. The three cables light up by attention weight.

  3. 3 · Add, layer by layerNeurons write into one shared stream.

    Each lamp has a key it fires on and a direction it writes. The 8 sliders on each tray show the vector after that block, the residual stream.

  4. 4 · UnembedThe vector picks the next token.

    It's compared with each project's direction. The tubes show the probabilities. The map is a 2-D projection of the vector's path. Click a lamp to switch it off, or drag the map to steer.
